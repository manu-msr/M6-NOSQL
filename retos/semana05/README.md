# Retos de la semana 5

- [Reto 09](reto09/README.md): elegir una necesidad de texto libre o de forma
  de códigos, implementar la estrategia y relacionar precisión con el plan
  observado.
- [Reto 10](reto10/README.md): construir una vista minimizada y una matriz de
  acceso para análisis, auditoría y administración.

Los retos usan conjuntos sintéticos independientes de las demostraciones. Cada
uno comienza en la consola, conserva después la solución en plantillas y
mantiene la solución docente en una carpeta separada.
