# Retos de la semana 2

- [Reto 03](reto03/README.md): interpretar planes y proponer una estrategia de
  indexación para tres consultas de portafolio.
- [Reto 04](reto04/README.md): construir un validador y comprobar documentos
  válidos e inválidos.

Los retos concentran los ejercicios de la semana y cuentan con una solución
docente separada. Cada uno utiliza datos sintéticos distintos de las
demostraciones y proporciona plantillas editables para conservar el trabajo.
