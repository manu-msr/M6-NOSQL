# Retos de la semana 3

- [Reto 05](reto05/README.md): identificar una coordenada inválida,
  transformar seis bienes a puntos GeoJSON y crear un índice `2dsphere`.
- [Reto 06](reto06/README.md): seleccionar siniestros cerrados dentro de una
  zona y agruparlos por tipo con conteo, monto total y promedio.

Los retos concentran la aplicación de la semana. Cada uno usa datos sintéticos
independientes de las demostraciones, proporciona plantillas de recapitulación
y mantiene la solución docente en una carpeta separada.
