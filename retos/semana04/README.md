# Retos de la semana 4

- [Reto 07](reto07/README.md): transformar ocho lecturas a una estructura con
  tiempo BSON `Date`, metadatos, medición, granularidad e índice temporal.
- [Reto 08](reto08/README.md): seleccionar siete siniestros, producir tres
  periodos e integrar exposición, frecuencia, severidad, extremos y cambios.

Los retos concentran la aplicación de la semana. Cada uno usa datos sintéticos
independientes de las demostraciones, proporciona plantillas de recapitulación
y mantiene la solución docente en una carpeta separada.
